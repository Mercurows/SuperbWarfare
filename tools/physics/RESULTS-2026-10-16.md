# TRACK 探针悬挂验证记录（2026-10-16）

本记录区分实际通过、失败与尚未验证。当前阶段按用户要求**只启用履带载具**：
`GroundVehicleAllowlist` 只注册 bmp_2 / bradley / m_1a_2 / plz_05 / prism_tank / t_90a / yx_100 / ztz_99a；
创造栏车辆容器与集装箱随机池按同一注册表过滤，其余载具不可获取且物品栏不可见；
轮式驱动套件移入 `WheeledDriveGameTests`（命名空间 `superbwarfare_physics_wheel`，默认不运行）。

所有 GameTest 使用 Forge 1.20.1 / Java 17 / Spark `1.20.1-1.1.5`，
固定 `1/60` 秒、每 tick 三子步、独立 `gametest-<UUID>` 世界；未改变验收阈值。

## 架构（本日落地）

- **探针悬挂**（核心 `ProbeSuspensionUnit`）：每侧一个单元、每个 `Support` 轮位一个探针。
  探针以点状小尖端（半径 0.06）沿板底线下扫；弹簧/阻尼按探针独立求解，
  阻尼比来自车辆 JSON（`TrackCompressionDampingRatio` / `TrackReboundDampingRatio`），
  只保留 reduced-mass/dt 数值上限；每探针力上限 = `TrackMaxSuspensionForce / 探针数`。
  力沿世界竖直施加在轮心，俯仰/侧倾由多点接触自然产生。
- **≤1 格接触**：地形楔面坡道为主（既有 17 项条件不变）；探针原始扫掠落空时，
  回退到 `LocalHeightField` 平滑面——仅当“原始列顶 − 3×3 邻域最低原始列顶 ≤ 1 格”，
  更高崖面保持原始碰撞。高度场按“中心方块变化 + 每 8 物理子步”周期重建，
  地形被挖空后回退面在 0.13 s 内刷新，不会持有旧地表。
- **牵引**：库仑封顶的显式力。滑移刚度在约 15 cm/s 滑移时达到 μ·N；
  侧向滑移在同一摩擦圆内抑制；滑行只损失 `TrackRollingResistance`；零载荷零力。
- **视觉**：整侧统一高度经 `TrackSuspensionProfile` 映射；履带轨迹动画预处理未改动。
- 刚性整侧底板（`PlanarTrackSupport`）已从 SBW 路径退役；核心类与其单元测试暂留。

## 迭代与失败记录（均为实际运行）

1. **球体探针（Ø=contactRadius）**：BMP 越坡成功（rise 1.35 / speed 9.19 m/s），
   双格墙拒绝；8 台静置中 5 台全绿。失败：M1A2、ZTZ99A、PLZ-05 在“整侧挖空后
   该侧必须卸载”断言处仍报告 touching/force——大球在 5 格深洞的洞壁棱角上被卡住，
   斜向法线（y≈0.37–0.53）产生伪支撑。
2. **点射线探针**：挖掘卸载全部通过；失败：YX-100、ZTZ99A 在 30 秒内未静置——
   射线起点在车辆下沉后进入地形内部，射线自盲，不再报告接触。
3. **点状小尖端扫掠（最终接触形状）**：**10/10 全部通过**。
   BMP 越坡 rise 1.33 / advance 11.27 / speed 9.19 m/s；双格墙 rise≈0 / advance 5.51 / z 1027.56。
   8 台履带 × 4 朝向 600 子步静置最大位移 1e-7–1e-3 格、水平速度 ≤2e-4 m/s（阈值 0.05 / 0.02）。
4. **接线核心单元 + 高度场后**：出现挖空回归（M1A2、PLZ-05）——高度场只在方块移动时
   重建，挖空时读到旧地表；修复为周期重建后复测 **10/10 通过**。Prism heading=0 曾在
   该轮观测期掉地一次，修复轮未复现，按随机世界波动观察。

## 履带转弯终验（第十二轮）

转向观测使用车体上轴投影的**带符号偏航角速度**；每次观测的第一物理采样只建立基线，
不把阶段切换时已有的稳定旋转误判为抽搐。控制层新增通用 `TrackMaxYawAcceleration=4 rad/s²`，
仅在驾驶员持续给出履带转向输入时限制偏航角速度变化率；目标偏航速率仍由
`TrackMaxYawRate=0.8 rad/s` 限制。测试阈值保持 `maxAngularDelta <= 0.08 rad/s`，没有放宽。

第十二轮实际读数：

- 原地枢转：`maxAngularSpeed=0.5733 rad/s`、`maxAngularDelta=0.02066`、`angularJitterSteps=0`、
  `drift=0.3769`；
- 行进转弯：`maxAngularSpeed=0.5915 rad/s`、`maxAngularDelta=0.01017`、
  `angularJitterSteps=0`、`speed=2.8068 m/s`、两侧最少支撑点为 2；
- 结论：行进转弯此前的单帧偏航冲击（约 `0.57 rad/s`）已消除，转弯用例通过。

同轮整套 13 项仍有 2 项与转向无关的失败：楼梯连续爬升辅助尚未通过，及 ZTZ-99A 静置
观测中的临界接地丢失；这两项没有借助转向阈值或静置阈值放宽处理。

## 2026-10-17 通用层修复（ZTZ-99A 复现）

用户实测反馈：99A 无法爬一格台阶、连续阶梯卡住，原地与行进转向仍抽搐。经复算与逐项验证，
确认并修复以下**通用实现**缺陷（均无车型分支）：

- **差速吞掉油门**：`VehiclePhysics.control` 先分别截断左右需求再取平均，99A 的
  `TrackDifferential=1.7` 使 `power=0.15 + 转向` 塌缩为 `+1.25/-1.25`，平均前进需求变成 0。
  已改为 `centerDrive` 与转向分量独立保存，`VehicleBody` 直接使用 `centerDrive`。
- **不存在的履带板质量**：探针不创建刚体，却仍从整车质量中扣除
  `TrackSupportMassFraction=8%`（99A 少 4.4 t）。已移除该预留，探针按整车质量分摊。
- **静载分配**：由平均分配改为按支撑点纵向 Voronoi 跨度分摊，端部按半个邻距镜像。
- **未经批准的爬坡力**：删除接触回调里“下一子步施加 0.6×车体重力”的延迟抬升，
  改为只改写可爬一格台阶的接触法线（位置、速度、接触点、流形距离均不改写）。
- **判定高度被楔面污染**：列高扫描混入了 `SLOPE`，使台阶低侧读成楔面高度、`rise` 缩水。
  已分离为两套数据：**爬坡判定只读 `TERRAIN`（真实方块）**，**探针支撑读 `DRIVABLE`
  （方块顶或楔面）**，法线仍取平滑坡面。
- **车体与楔面互撞**：车体碰撞改为只含 `TERRAIN`，楔面只由探针承载；
  两格墙仍按真实方块拒绝。
- **客户端叠加姿态**：物理接管车辆不再叠加 `fakePitch/fakeRoll` 惯性摆动。
- **楼梯测试油门衰减**：夹具只设 `power` 不按前进键，旧引擎按 `0.96/tick` 衰减到 0；
  已改为持续保持前进输入。

ZTZ-99A 实测（驾驶组）：一格台阶 `rise=1.35 / 8.8 m/s`、无楔面台阶 `rise=1.32`、
两格墙正确拒绝 `rise=0.003`、原地枢转 `drift=0.2303`、行进转弯通过。

### 尚未通过：连续三阶普通方块楼梯

车停在 `z=1028.38`（第一级踏面在 `1033`），速度约 0，两侧探针只有首尾承载：

```
travels=[+0.057, -0.115, -0.240, -0.234, -0.044, +0.147]
forces =[94563,      0,      0,      0,   7116, 166667]   // 合计 268 kN < 车重 539 kN
```

机制：楔面按 `RUN_BLOCKS=3` 在台阶前 3 格起坡，长车体（支撑跨度 5.65 格）车头先被顶起，
中段探针锚点相对坡面下沉、行程转负、弹簧卸载，车体前倾后停在坡上。
已尝试并回退：楔面高度改用真实地面（一格台阶全失效）、楔面低端水平延伸/下沉
（坡面单测载荷下滑或停在 tail 上）、修正探针行程公式（静置高度偏 0.06）、
`RUN_BLOCKS=2`（坡面几何单测 5 项失败）。这些方向都不能作为修法。

核心库新增 `ProbeOverWedgeTest`（原生、约 10 s）稳定复现“6 探针只剩 2 根承载”，
后续修法可在此用例内验证，不必每轮跑整车。

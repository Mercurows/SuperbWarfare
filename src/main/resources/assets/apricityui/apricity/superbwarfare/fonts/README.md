# Weapon editor font

- Font: Source Han Sans CN Medium (思源黑体), Adobe's Simplified Chinese regional subset.
- Upstream: https://github.com/adobe-fonts/source-han-sans
- Font file: https://github.com/adobe-fonts/source-han-sans/blob/release/SubsetOTF/CN/SourceHanSansCN-Medium.otf
- License: SIL Open Font License 1.1; the upstream copyright notice and full license are in `OFL.txt`.
- The upstream font binary is included without modification. Keep `OFL.txt` with it when redistributing.

All weapon editor text uses this font, including headings, body text, attribute values, controls, mount labels and attachment tooltips. The Minecraft font outside this editor is unaffected.

ApricityUI 1.2.7 also bundles Minecraft Seven/Ten fonts with MIT attribution, but those files do not contain the Chinese heading glyphs used on this page.

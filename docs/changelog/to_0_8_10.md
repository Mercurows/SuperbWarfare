# SuperbWarfare 0.8.9.2 → 0.8.10

适用版本为 Minecraft 1.20.1 / Forge。基线为 `0.8.9.2-1.20` 的 `65d985a644`，目标为 `superbwarfare` 的 `0f691e0723`（`0.8.10-snapshot`）。下文记录两个提交最终树之间的变化，并列出扩展代码、数据包和资源包涉及的主要迁移点。

类和方法按源码中的完整限定名书写。Kotlin 顶层函数使用包名加函数名。方法签名也使用完整类型名，泛型参数沿用源码中的名称。

## 枪械属性、状态与数据加载

- **属性修改链（PMC）重做。** `com.atsuishio.superbwarfare.data.gun.DefaultGunData` 改为 Kotlin `data class`，模板字段以只读属性为主。原来的就地 `com.atsuishio.superbwarfare.data.gun.DefaultGunData.limit()` 改为返回副本的 `com.atsuishio.superbwarfare.data.gun.DefaultGunData.clamped(): com.atsuishio.superbwarfare.data.gun.DefaultGunData`。`com.atsuishio.superbwarfare.data.PMC` 构造器增加可选起点 `computed: DEFAULT_DATA? = null`，新增 `com.atsuishio.superbwarfare.data.PMC.dirtyProps()` 和 `com.atsuishio.superbwarfare.data.PMC.diffSnapshot()`，可查询显式修改的属性。配件在开火模式前应用，充能动作在弹种后、Perk 前应用。

  - 读取枪械最终属性使用 `com.atsuishio.superbwarfare.data.gun.GunData.get(prop: com.atsuishio.superbwarfare.data.gun.GunProp<*, T>): T`，可用新增的 `com.atsuishio.superbwarfare.data.gun.GunData.invalidateProperties()` 使计算结果失效。

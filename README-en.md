# SuperbWarfare

[中文](./README.md) | **[English](./README-en.md)**

## Introduction

A "Superb" military-themed Minecraft Mod.

## Installation Guide

1. Ensure using Minecraft version 1.20.1
2. Ensure Forge 47.2.0 or above is installed
3. Ensure Curios Api mod 5.4.2-1.20.1 or above is installed
4. Ensure Geckolib mod 4.4.6-1.20.1 or above is installed (version before 0.8.0 requires Geckolib 4.4.4)
5. Place the mod jar file into mods folder

## Integration

Install Cloth Config mod 11.1.106-1.20.1 or above to enable in-game configuration adjustments.

Controller support is optional: install [Controlify: Forgified 2.1.9](https://www.curseforge.com/minecraft/mc-mods/controlify-forgified) and its YetAnotherConfigLib dependency for Forge 1.20.1. Controlify requires Forge 47.3.19 or newer; the development environment uses Forge 47.4.10. Configure the mod's actions under **Superb Warfare** in Controlify's bindings screen, or add them to its radial menu.

Defaults: right trigger fires, left trigger aims, and B/Circle reloads a held gun. In vehicles, the left stick steers, A/Cross ascends, B/Circle descends, and pressing the left stick activates the vehicle's Ctrl action. The right stick controls the view and aircraft steering, using Controlify's sensitivity and deadzone settings. Other actions start unbound. The seat action cycles to the next empty seat; next/previous weapon performs the mod's scroll action (vehicle weapons, scopes, zoom, or free-camera distance).
